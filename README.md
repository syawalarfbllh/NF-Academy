Selamat datang di repository ini!

Tujuannya untuk mendokumentasikan pengalaman, proyek, serta pembelajaran yang dilakukan selama program MBKM berlangsung.

---

## 🚀 Tentang MBKM
**Merdeka Belajar Kampus Merdeka (MBKM)** adalah program dari Kementerian Pendidikan, Kebudayaan, Riset, dan Teknologi yang memberikan kesempatan bagi mahasiswa untuk mengasah kemampuan sesuai minat dan bakat di luar program studi.  

Di **Nurul Fikri Academy**, program MBKM berfokus pada:
- 💻 **Pengembangan Teknologi & Pemrograman**
- 🌐 **Proyek Berbasis Industri**
- 🤝 **Kolaborasi Tim & Networking**
- 📚 **Penguatan Soft Skill & Hard Skill**
